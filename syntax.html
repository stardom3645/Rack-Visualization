RackML 문법

RackML 문서는 반드시 외부에 <racks> 요소를 포함해야 합니다.

<racks>

<racks> 요소는 다음과 같은 속성을 가질 수 있습니다:

base
링크에 사용할 기본 URL

<racks> 요소는 0개 이상의 <rack> 요소를 포함할 수 있습니다.

<rack>

<rack> 요소는 다음과 같은 속성을 가질 수 있습니다:

height
해당 랙의 높이 (단위: rack unit)
name
랙의 이름. SVG에서 랙 위에 표시됩니다.

<rack>의 자식 요소

<rack> 요소는 다음과 같은 요소들을 포함할 수 있습니다:

<cables>
케이블 관리 시스템
<firewall>
방화벽
<gap>
빈 공간
<keyboard>
키보드
<kvm>
KVM 스위치
<monitor>
디스플레이 장치
<patch>
패치 패널
<pdu>
전원 분배 장치(PDU)
<san>
SAN 스토리지
<server>
서버
<switch>
네트워크 스위치
<tape>
테이프 드라이브
<ups>
무정전 전원장치(UPS)

이러한 요소들은 다음과 같은 속성을 가질 수 있습니다:

at
장비가 위치하는 최하단 랙 유닛
height
장비의 높이 (단위: rack unit)
href
추가 정보를 위한 URL. SVG에서 클릭 가능하게 됩니다.

※ 문법에 맞지 않는 XML은 제대로 렌더링되지 않을 수 있습니다.
